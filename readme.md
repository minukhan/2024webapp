# 🌐 2024 웹 애플리케이션 개발

## 기간 : 2024-08 ~ 2024-10

## 📖 프로젝트 개요  

이 저장소는 현대적인 웹 기술과 프레임워크를 사용하여 웹 애플리케이션 개발을 학습한 예제와 프로젝트들로 구성되어 있습니다. 

실습 예제를 통해 프론트엔드 개발의 기초부터 실전까지 배울 수 있습니다.

---

## 🚀 사용된 기술 스택  
- **HTML & CSS**: 웹 페이지의 구조화 및 스타일링  
- **JavaScript**: 동적인 웹 기능과 상호작용 추가  
- **Vue.js**: 사용자 인터페이스 구축을 위한 경량 JavaScript 프레임워크  
- **React**: 리액티브 UI 컴포넌트를 만드는 인기 있는 JavaScript 라이브러리  
- **To-Do 앱**: 위 기술을 통합한 할 일 관리 애플리케이션 프로젝트

---

## 🌟 주요 특징  
- **반응형 웹 디자인**: 다양한 화면 크기에 맞춰 웹 페이지를 구현하는 방법 학습  
- **동적 웹 애플리케이션**: JavaScript와 프레임워크를 활용해 동적인 기능 구현  
- **프레임워크 활용**: Vue.js와 React를 사용하여 컴포넌트 기반 UI 개발
